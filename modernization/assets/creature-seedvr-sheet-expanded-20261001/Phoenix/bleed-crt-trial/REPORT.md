# Phoenix pre-inference colour bleed and light CRT comparison

Completed new authenticated Manager FIFO SeedVR2 job 4b56ffe927134cf79938127c10718721. Eight PBLD frames, original dimensions/offset layout, input 768x320 RGBA, output 1536x640 RGBA. Model profile stays seed42/noise0, Lab, batch1, tiled VAE and CPU tensor offload. IDs/input/output hashes are in manifest.json. Before inference, all alpha-zero RGB pixels within each isolated cell receive nearest original opaque RGB, with alpha unchanged. No output unmatting or donor repair. Original sources reverified; no runtime changes.

This cell-wide hidden RGB extension is a deliberately strong test, not just a narrow two-pixel bleed. It removes black/grey hidden RGB at input but produces an extended colour field which the RGB model and Lab correction see. Native returned alpha remains unchanged. The first-frame white-background inspection does not show a robust halo fix: added feather texture and coloured/grey fringes remain, with increased changes in local detail. This trial does not support adopting this particular full-cell colour-bleed configuration. A bounded near-edge input bleed would be a distinct further experiment, not a proven fix.

Original-source display comparisons include nearest 2x, gamma-correct beam-only 2x and weak CRT-style 2x. The latter two are CPU adaptations of the CRT-Lottes horizontal Gaussian/vertical beam formulas, with horizontal hardness -6, vertical hardness -8, scan attenuation strength 0 or 0.2. Warp, RGB mask, bloom and interlace are disabled. sRGB is linearized for filtering and converted back afterwards. These are explicitly a light beam prototype, NOT execution or validation of full CRT-Lottes/Easymode/Guest/Royale GPU shaders. xBRZ and other uninstalled models were not executed; the requested two recommended routes were tested.

The beam prototype softens pixel transitions while preserving original anatomy and coarse texture. At exact 2x output, the selected Gaussian scan attenuation has equal phase on both output rows, so beam-only and weak-scanline arms are nearly identical; it must not be interpreted as visible strong scanline simulation. It reconstructs no new detail. The source sprite is first composited on each test background, then filtered; there is no per-channel alpha CRT filtering. This is a static source-region experiment, not a screen-anchored live battle acceptance test. Full-frame scene/UI/readability/motion/performance remain unverified.
