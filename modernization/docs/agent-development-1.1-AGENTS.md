# Remastered 1.1：Agent 工作入口

先读 [开发手册](Documentation/Agent-Development/README.md) 和 [源码索引](Documentation/Agent-Development/source-index.json)。它们面向 2026-10-02 的正式 1.1 基线；收到更新版本时，以可信版本来源重新确认身份。

- 玩家入口是根目录 `MagicMayhem-Remastered.exe`；原生引擎、依赖和资源在 `runtime/`。开发材料在另行提供的工程 `modernization/`，不是玩家目录中的用户配置子目录。
- 从当前版本继续开发，保留已有功能。地址补丁先核对完整引擎哈希、预期字节、ABI 和模块 hook；未知版本拒绝固定地址修改。
- 101、102、103、wrapper 的对应源码快照不同，按手册与索引选择。保留不改模块的内嵌资源字节，不从历史目录整包覆盖。
- 独立 UI 内容原生 1920×1440；战斗保留 1280×720 场景/HUD，按既有 2× 合成。输出大小、Present FPS、不同画面数和逻辑更新频率分别验证。
- 保留中文、原存档格式、OGG、FMV、PNG loader、快捷键、地形/寻路/屋顶行为、AI budget300 和 danger16/128 的单人条件及多人回退。
- 在独立副本开发，一次处理一个明确问题；有序多项任务按顺序完成。性能优化一次一项，等待用户反馈后继续。
- 修改前备份，构建安装核对哈希并提供回滚；保留 Save、偏好、显示参数、快捷键和 AI 学习状态。
- 默认由用户进行游戏验收；仅在本次用户明确授权时运行隔离游戏测试。获准后优先后台输入、只读遥测和程序化像素验证，仅管理自己拥有的进程。
- 历史构建/安装脚本可能含作者机器路径与多目标安装，不直接运行到玩家包；先审查和参数化。
- 将确定的工作规则记录在 AGENTS.md，设计/证据记在工程文档，计划记在任务列表，行为要求记在测试。勿只依赖聊天历史，勿记录凭证或临时状态。
- 玩家包不是原游戏完整源码。开始修改前确认所需扩展源码、头文件、工具、测试和资源来源已提供。
