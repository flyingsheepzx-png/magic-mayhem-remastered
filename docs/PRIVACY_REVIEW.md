# 首次公开的隐私检查

本仓库从开发目录中的显式源码/文档集合导出，使用全新 Git 历史。原工作目录的 Git 历史、remote、提交者私人元数据和机器配置未导入。提交使用 GitHub 的 noreply 地址。

公开前检查全部待提交文件的路径与内容，并复核 Git 暂存区：

- 排除玩家存档、运行目录、个人配置、日志、转储、备份、模型权重、生成图像/视频、构建产物和环境文件。
- 检查私钥、常见 API/GitHub 令牌、凭证字面值、带密码 URL、个人用户目录、邮箱和内网地址。
- 匿名化历史文档中的个人用户目录；可选素材脚本不再写死作者的凭证文件位置，改读 `MM_LOCAL_MODEL_CREDENTIAL` 环境变量。环境变量内容与凭证文件均不随仓库提供。
- 保留第三方上游代码中的公开作者邮箱和许可证声明，它们不属于项目作者的私人账号。
- 唯一随源码保留的二进制资源是上游 wrapper 自带图标。原游戏图标与测试机器码均由使用者在本地从已验证玩家文件提取到被忽略的 `out/`。

可重新运行 `python tools/check_publication.py` 检查跟踪文件，或添加 `--staged` 检查暂存内容。检查只报告文件路径、行号与规则名，不打印疑似秘密。人工审查与规则扫描共同使用；规则扫描不能证明任意未来修改都绝无隐私风险。
